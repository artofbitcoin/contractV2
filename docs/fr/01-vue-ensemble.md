# 1. Vue d’ensemble de DODO V2

DODO V2 est un protocole d’échange décentralisé fondé sur le Proactive Market Maker. Le prix et la liquidité sont pilotés par une courbe qui cherche à rapprocher l’exécution d’un prix de référence.

Le dépôt sépare les pools, les routeurs, les registres et les contrats de liquidité. Cette séparation permet d’étudier le chemin complet d’un swap sans confondre l’interface utilisateur avec le règlement on-chain.

Le parcours français suit le PMM, les pools privés et publics, les contrôles de frais, puis les points de confiance liés aux paramètres et aux oracles.

Cette documentation décrit le code et ses limites opérationnelles ; elle ne constitue ni un audit ni une recommandation financière.
