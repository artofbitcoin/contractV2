# 4. Gouvernance et limites

DODO V2 expose des paramètres qui influencent la courbe, les frais, les permissions et les adresses de référence. Leur gouvernance est donc aussi importante que la formule du PMM.

Les contrats d’usine, les registres et les contrôleurs déterminent qui peut créer un marché, modifier sa configuration ou effectuer une opération administrative. Il faut distinguer ces rôles du simple fournisseur de liquidité.

Les risques principaux sont la mauvaise configuration du prix cible, la liquidité adverse, le slippage, les tokens non standards et les appels en chaîne depuis un routeur.

Dernier chapitre : le dépôt contient des tests et rapports d’audit qui servent de points de vérification, mais aucune installation, compilation ou exécution n’a été réalisée dans ce parcours documentaire.
